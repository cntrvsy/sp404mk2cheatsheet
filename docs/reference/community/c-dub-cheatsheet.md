## Page 1

```text
Roland SP404 MK2 Notes (C-Dub's
Cheat Sheet)
  Sample    Playback        Mode
    PAD + HOLD will play the sample without having to hold down the
     pad
     BANK buttons select banks
        Press twice to select the alternate bank
     SHIFT + EXIT or EXIT (x4) to STOP ALL SAMPLES
     One Shot Playback
         Allows longer samples to play all the way through without being
         retriggered when the pad is pressed again or by the pattern sequencer
              Also allows you to put a long sample on the first beat of a pattern
              and put drums over the top, with the one shot sample only
              triggering when the pattern repeats
              Good for evolving patterns over an ambient sound
         PAD to select sample > push VALUE ENCODER + GATE to set sample as
         ONE SHOT (GATE will pulse)
  Pattern Select    Mode
    PATTERN SELECT to enter Pattern Select Mode
        Pads will flash purple
     PAD to play a pattern, and again to stop
        To play a different pattern next, press a different PAD while the first
        pattern is playing
        When the current pattern is finished, the next one will play
     Delete a pattern
        DEL + PAD + ENTER
        Pad will go blank when the pattern has been deleted
        DEL + EXIT > PAD to select bank > DEL deletes all patterns in a bank
     Record a pattern
        REC + flashing PAD (only available pads will flash)
        This will bring up record settings
```

   REC to start recording

   In PATTERN SELECT mode, PAD to select pattern

       Pads will be muted when selected
       REC to record MUTE AUTOMATION

Rehearsal Mode
   While already recording, press REC to enter REHEARSAL mode, which
   allow you to try out samples while the pattern is looping without

Undo

## Page 3

```text
Hold PAD for the sound you want to erase
   Press DEL again to go back into recording mode
Pattern Edit
   PATTERN EDIT to edit pattern parameters
       BPM using CTRL 1
       LENGTH using CTRL 3
       DUPLICATE or CROP using VALUE ENCODER
Pattern Chain
   Allows you to chain your patterns together into a song
   PATTERN SELECT > HOLD (pads will flash green) + PAD to select a
   CHAIN SLOT
   PADS to select pattern to enter into the chain
   REMAIN to select repeating options
   SUB PAD to play chain
   VALUE ENCODER to highlight steps in the chain and DEL to delete
Resampling Pattern Chains
   PATTERN SELECT > RESAMPLE > PAD for resample destination
   HOLD + PAD to select the chain you want to resample
   SUB PAD to playback and resample
   REC to end the resample
TR Rec Sequencer
   PATTERN SELECT > REC > PAD to select destination
       Set your recording preferences
       CTRL 3 now controls SHUFFLE
       If you have more than one bar, use VALUE ENCODER to move
       between bars
   REMAIN to enter TR REC mode
   REC to start recording (green sequence follow light will run through the
   pads)
   Hold SUB PAD to audition sounds in a bank
   When you have selected a sound release the SUB PAD and enter steps
   using PADs
   CTRL 3 to change velocity entered on steps
   Substeps
       There are a variety of SUBSTEP types available for adding variation,
       rolls, etc.
```

## Page 4

```text
Use CTRL 1 to change substep type > enter a step to use that
            substep type
       Motion recording
            You can record SUBSTEP, VELOCITY, and PITCH control change into
            a TR REC sequence
            While recording, hold ROLL and adjust CTRL 1-3 to record the
            parameters
   Effects Motion Recording (Automation)
       Allows you to record effects changes in patterns
            Also includes turning on / off effects
       Works in both real time and TR Rec modes
       PATTERN SELECT > PAD to select pattern > REC to start recording
       MARK to start motion recording
       START / END turns MOTION ON / OFF
       SHIFT + MARK deletes motion
   Copying Specific Pattern Samples
       Allows you to copy over only certain sounds in a pattern so that you can
       create variations (e.g. just the kick and bass sounds)
       PAD to select pattern > REMAIN to go into sample selection
       PADS to select the samples to copy
       REMAIN to select destination of copied samples > VALUE ENCODER to
       finish
   Convert / Bounce Patterns to Samples
       PAD to select pattern > COPY > PAD to select pattern
            REMAIN to select individual samples if you only want parts from the
            pattern (good for creating stems)
       PATTERN SELECT to change from PATTERN to SAMPLE
       PAD to select destination
       COPY or VALUE ENCODER to finish copying the pattern to a sample
Resampling      Method
  Copying sounds from one pad to another
       COPY > PAD to select sample to copy > BANK for destination > PAD for
       destination > COPY to complete the copy
   Copying samples or patterns to a different PROJECT
```

      REC to end the recording
SkipSkipBack   Sampling

## Page 7

```text
Auto Mark
          Press VALUE ENCODER > AUTO MARK
          CTRL 2 to select AUTO MARK MODE
               TIME DIVISION sets marks at equal time divisions depending on
               the setting
                   Change the time division using CTRL 3
      Level
          Adds marks depending on level - higher number = more marks
      Transient
          Adds marks at transient points, like drum hits, with settings of
          HARD, MID, SOFT using CTRL 3
   Assigning chops to pads
      Manual
          In the CHOP menu, press the VALUE ENCODER to enter the menu
          PADS to select destination of chops
          CTRL 3 to change GATE parameter for the chops
      Automatic
          VALUE ENCODER to select starting pad
          MARK to assign to the following pads > VALUE ENCODER to assign
          > VALUE ENCODER to finish
Pitch  &  Speed
  PAD to select sample > PITCH / SPEED to enter the menu
      To modify multiple sounds at once, put them in a MUTE GROUP using
      SHIFT + PAD 8
      When you are in PITCH / SPEED, press COPY > your mute group will
      flash and any adjustments will be made to all of the samples in the mute
      group
           You can use this for BPM, VOLUME, BPM SYNC, GATE, LOOP,
           REVERSE
   SHIFT + VALUE ENCODER to select VINYL or VARISPEED
      In VINYL mode, pitch and speed are tied together
      In VARISPEED mode, pitch and speed are independent
           SHIFT + VALUE ENCODER to select an algorithm
               BACKING - suitable for clear attacks like drums
               ENSEMBLE - good for sustained instruments like bass or pads
```

```text
Controls
     CTRL 3 to adjust VOLUME
         SHIFT + CTRL 3 adjusts PAN, including setting to MONO (which is
         good for drum loops)
     CTRL 2 adjusts PITCH
     CTRL 1 adjusts SPEED
   BPM
     Auto Detect
         Push VALUE ENCODER to select BPM range to scan (to prevent
         detection of half / double time) > VALUE ENCODER to detect
     Manual
         Turn PUSH ENCODER to select MANU or MANU-F (for decimal
         values) > push VALUE ENCODER > select BPM > push VALUE
         ENCODER
Envelope
  PAD to select sample > SHIFT + PITCH / SPEED to enter the menu
   Controls
       CTRL 1 adjusts ATTACK - how long it takes for the sound to start on the
       sample
       CTRL 2 adjusts HOLD - how long the sample plays for
       CTRL 3 adjusts RELEASE - how long the sample takes to fade out
Sample   Mode
  BPM Sync
      BPM SYNC to enter this mode, which syncs all samples in the bank to
      the BPM of the bank, making it easy to get all of the samples in a bank
      playing at the same speed
          SHIFT + PAD 11 takes you to the TAP TEMPO menu where you set
          the BPM of the bank
          VALUE ENCODER to set the BPM
          Tap SUB PAD to tap tempo
   Gate
      With gate OFF, the entire sample will be played when you tap a button
      With gate ON, you have to hold down the pad to play the sample
      SHIFT + GATE turns gate on / off for ALL SAMPLES in the bank
```

```text
Loop
       When loop is ON, the sample will loop from the beginning or the loop
       point which you have set up
       SHIFT + LOOP enables PING PONG looping

       REVERSE plays the sample backward
   Roll
       ROLL will roll the playing sample in the specified time division

MFX
 Top 5 effects and assignable MFX buttons surround the display
      MFX + CTRL 3 (or VALUE ENCODER or PAD) to select the effect to

      PADS

      second page of parameters
      Hold VALUE ENCODER to access second parameter page
   While in the EFFECTS MENU, press REMAIN + EFFECTS PADS to
   keep the menu on the display until you remove the effect
   Setting the effect loaded to MFX on startup
       SHIFT + PAD 13 (UTILITY) > EFX SET > CTRL 3 to OTHER tab > MFX
       TOP to select the effect you would like loaded in MFX on startup
BUSBUSFX
      FX gives a second level of effects
      Select BUS 1 or BUS 2 and independently select / turn on effects and
      change effects settings
      REMAIN + BUS FX swaps the effects between BUS 1 and 2
   By default, all samples are sent to both of the effects
      While in BUS 1
```

```text
Allows you to play samples like an instrument chromatically
   Turn VALUE ENCODER to change root note by 4 semitones, or SHIFT +
   ENCODER to change by 1 semitone
   Otherwise operates exactly like 16 VELOCITY described above
   REMAIN to choose mode
        MONO
        LEGATO
        POLY
   Push VALUE ENCODER to restrict instrument to different scales (MAJ,
   MIN, DORIAN, PHRYG, CHROM)
   To record chromatically into patterns:
        While in RECORD, press REC to enter REHEARSAL MODE
        Select the sound you want to record chromatically
        SHIFT + PAD 4
        REC to go into RECORD mode
        play notes to record
        EXIT to end recording
SHIFT + PAD 5 (EXCHANGE)
   Allows you to swap sounds between pads
   PAD to select first sample > PAD to select second sample > COPY or
   VALUE ENCODER
SHIFT + PAD 6 (INIT PARAM)
   Initializes a sample, removing any changes you made to it using pitch,
   etc.
SHIFT + PAD 7 (PAD LINK)
   Allows you to play multiple pads using a single pad
   PADS to select which ones you would like to link > EXIT
   Now when you play one of the linked pads, all of them will play
SHIFT + PAD 8 (MUTE GROUPS)
   Allow you to choke other sounds (hi-hats, chopped samples, etc.)
   There are 10 mute groups with 16 samples each (can be split between
   banks)
   Mute groups can also be used to change multiple sounds at once
SHIFT + PAD 9 (METRONOME)
   Turns the metronome on / off
```

```text
FACTORY RESET
          ALL DATA - deletes all data and all samples
          SYSTEM DATA - deletes all system data but does NOT delete
          samples
   SHIFT + PAD 14 (IMPORT / EXPORT)
      IMPORT / EXPORT from SD card
      FORMAT SD card
   SHIFT + PAD 15 (PAD SETTING)
      Changes to PAD SENSITIVITY, LED colors, BUS COLORS etc.
   SHIFT + PAD 16 (EFX SETTING)
      See EFX SETTINGS above
   SHIFT + BUS FX (MUTE BUS)
      Allows you to mute any sounds that are routed through BUS 1 and 2
      Samples that are excluded from the effects busses (lit white) are not
      affected by the mute bus
   SHIFT + HOLD (PAUSE)
      Pauses any playing audio
   SHIFT + EXT SOURCE (INPUT SETTING)
      See RECORDING EXTERNAL SOURCES above
   SHIFT + SUB PAD (PROJECT)
      PAD to LOAD a saved project
      COPY to copy projects
      DEL to delete projects
TRSTriggering
       MIDIthe SP404 using MIDI IN
       MIDI MODE A
          PADS are triggered on CHANNELS 1-10 for BANKS A-J
          Notes start from C1 on PAD 13 to D#2 on PAD 4
       MIDI MODE B
          BANKS A-E on one MIDI channel
          BANKS F-J on a second MIDI channel (1/2 - 2/3 up to 10/11)
          NOTE OFFSET moves where the notes start from
          Gives you 80 note range per channel
```
